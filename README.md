# Selaus Hemrom Premium Website

A responsive one-page personal + business portfolio for:
- Selaus Hemrom
- Selaus Academy
- Selaus Digital Solutions

## Deploy with GitHub + Netlify
1. Create a GitHub repository named `selaus-hemrom-website`.
2. Upload all files in this folder.
3. In Netlify: Add new project → Import an existing project → GitHub.
4. Select the repository.
5. For this static HTML site, leave Build command empty and publish the repository root.
6. Deploy.

## Replace before publishing
- `assets/profile-placeholder.svg` with a professional photo named `profile.jpg` and update the `<img>` path in `index.html`.
- Replace the four `work-placeholder.svg` images with real portfolio/training/certificate images.
- Verify your final email, social URLs and any career dates/numbers.
- Add your custom domain later through Netlify Domain management.

## Important
Do not put passwords, API keys, payment information, Meta access tokens or other secrets in this repository.
